## 🎯 Overview
CareerShield AI is a real-time, multimodal forensic intelligence system designed to detect and flag recruitment fraud before it impacts job seekers. It evaluates urgency linguistics, domain spoofing, and salary-to-skill anomalies to protect users from credential harvesting and financial extortion.

## ⚙️ Tech Stack & Generative AI Disclosures
As per Omnikon rules, we explicitly disclose the use of the following tools and APIs:
- **Frontend:** React, Tailwind CSS
- **Backend:** Python (FastAPI), SQLite
- **Generative AI Engine:** **Google Gemini API** (Multimodal Vision & NLP for deterministic threat scoring)
- **Security:** Custom PII (Personally Identifiable Information) Sanitization Engine
- **UI/UX & Graphics:** Canva, Adobe Illustrator
